OurDream Race Generator — Phone Install

IMPORTANT: Do not run index.html from the phone's file preview. Install/host it through HTTPS so the service worker can make it truly offline.

EASIEST WITH GITHUB PAGES:
1. Upload every file/folder in this package to the root of your Race-Generator repository.
2. On GitHub: Settings > Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Choose main and /(root), then Save.
5. Open the GitHub Pages address GitHub gives you.

IPHONE/IPAD:
1. Open the Pages address in Safari.
2. Tap Share.
3. Tap Add to Home Screen.
4. Launch OurDream Races from the new home-screen icon.
5. After the first successful load, the app's core files are cached for offline use.

ANDROID:
1. Open the Pages address in Chrome.
2. Tap Install App / Add to Home screen when offered, or use the Chrome menu.
3. Launch the installed app once while online. Core files are then cached for offline use.

The full 2,000-race encyclopedia is embedded in index.html.
