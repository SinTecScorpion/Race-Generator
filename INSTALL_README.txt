R5.0.24 HAIR SCOPE FIX

WHAT CHANGED
- Random hair remains enabled and now chooses from a larger non-bald hairstyle pool.
- Shaved/bald was removed from the normal character hair pool and normal Hair Style selector.
- Realistic, Anime, Master/Base, and Blender Finished keep the character's generated hairstyle.
- Blender B&W alone temporarily hides the hairstyle so the scalp is visible for modeling.
- The B&W bald presentation cannot overwrite the saved character hairstyle or cross-style identity.

INSTALL
Replace the Race-Generator repository root index.html with this index.html.
